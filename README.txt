Revisão final responsiva - Marmitaria K'Delícia

- CSS limpo e consolidado, removendo regras conflitantes acumuladas.
- Header sticky/fixo no topo sem cobrir títulos ou imagens.

Como usar:
1. Extraia este ZIP.
2. Copie sua pasta img original para dentro da pasta extraída.
3. Substitua os arquivos do projeto pelos arquivos deste pacote.
4. Abra index.html com Live Server.
